## About
Simple implementation of memory game: find identical pairs among the set of cards with images.

## How to run the game:

### Option №1 
Through deployed page - https://almondchips.github.io/memory-game/

### Option №2 
1. Go to any empty folder on your PC
2. Open it with bash
3. Clone the repo via this command:
```
git clone https://github.com/AlmondChips/memory-game.git
```
4. Go into the memory-game folder
```
cd memory-game
```
5. Then run this command to switch to the brunch with project:
```
git checkout memory-game
```
6. Run index.html with a live server like the one from VS code for example. You should have gotten one already for sure :)

## How to play
- You can start new game by clicking "New game" button.
- Click the cards on the boards and look for duplicates.
- After your eventual win u can restart the game by clicking same "New game" button either on the congratulation window or header's one.
- You can view your records by clicking "Leaderboard" button. You can view up to 10 first best records.
- You can restart the game if you feel so at any time - it won't be recorded into a leaderboard unless you already won at the moment.

  ## Bugs
  - There is little visual bug at the first launch: images arent pre-loaded, so you can see them flicker for a moment after opening a card.
